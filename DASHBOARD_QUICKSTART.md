# 🚀 Dashboard Quick Start (30 seconds)

## Launch in 3 Steps

### 1. Open Terminal
```bash
cd /Users/jacklegnon/Desktop/golf_data
```

### 2. Launch Dashboard
```bash
./launch_dashboard.sh
```

### 3. Open Browser
Dashboard automatically opens at: `http://localhost:8501`

**If browser doesn't open**: manually go to http://localhost:8501

---

## Run Your First Prediction

1. Click **"🎯 Run Predictions"** in sidebar
2. Fill in the form:
   ```
   ESPN ID: 401811929
   Tournament Name: American Express
   Purse: 9600000
   Tournament Type: Standard
   ```
3. Click **"🚀 Run Predictions"**
4. Wait 1-2 minutes
5. View top picks!

## Dashboard vs Command Line

| Feature | Dashboard | Command Line |
|---------|-----------|--------------|
| **Ease of Use** | ⭐⭐⭐⭐⭐ Visual forms | ⭐⭐ Commands |
| **Speed** | Same (1-2 min) | Same (1-2 min) |
| **Charts** | ✅ Built-in | ❌ None |
| **Player Search** | ✅ Yes | ❌ Manual |
| **Best For** | Exploring, analyzing | Automation, scripting |

**Both use the same prediction engine** - results are identical!
